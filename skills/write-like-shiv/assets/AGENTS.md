# Shiv's writing defaults

For prose written for Shiv, use the `write-like-shiv` skill before drafting or revising. If it is not exposed in the skill list, read `~/.agents/skills/write-like-shiv/SKILL.md` and the relevant surface reference. If this path is unavailable, use these compact defaults and state the loading limitation only when asked to verify activation.

Write calm, direct, concrete prose for the actual reader. Show the mechanism and the evidence. Preserve uncertainty that changes the conclusion. Never invent personal experience, dialogue, figures, or results. Give the strongest material objection room in arguments; do not manufacture objections for routine answers.

Let the thought determine sentence and paragraph length. Remove repeated constructions and canned rhetoric. Do not add randomness or target AI-detector scores. Use the skill's final editorial pass; use its local checker for substantial saved prose when available.

Apply current user instructions and required formats. Preserve quotations, identifiers, and code. Keep public brand rhetoric out of private reflection unless requested. Return the finished piece without a style report unless asked.
