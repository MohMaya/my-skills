# Sources

Rewritten for this repository on 2026-10-18 from `golang-pro` in [Jeffallan/claude-skills](https://github.com/Jeffallan/claude-skills) (MIT, per the upstream skill's frontmatter; no separate license file ships on disk), imported in commit `40c5f7c`. Rules are rewritten, and upstream defects are not carried over: the `constraints` import, `tt := tt`, `// +build`, `golang/mock`, `alpine:latest` root images, gin, `lib/pq`, and zap defaults, hand-rolled `Map` and `Filter`, functional options and interface segregation by default, "document all exported", and the worker pipeline in the upstream `SKILL.md`, which sends on `errCh` only on failure, so a fully successful run waits out its 30-second timeout and returns an error. Rules a linter in [`lint/.golangci.yml`](../../lint/.golangci.yml) enforces are left out.

Checked on 2026-10-18 against Go 1.27.2 (latest release), 1.26.9 (latest 1.26), and `golang.org/x/sync` v0.24.0. Doc text was read with `go doc` on Go 1.27.1, and the shutdown example was compiled, vetted, and run (SIGTERM exits 0; a bound port exits 1 with the error):

- Release history: [Go 1.20](https://go.dev/doc/go1.20) (`errors.Join`), [1.21](https://go.dev/doc/go1.21) (`min`, `max`, `clear`, `slices`, `maps`, `cmp`, `slog`, `WithoutCancel`, `AfterFunc`), [1.22](https://go.dev/blog/routing-enhancements) (`ServeMux` patterns), [1.24](https://go.dev/doc/go1.24) (`os.Root`, `T.Context`, `B.Loop`, `tool` directives), [1.25](https://go.dev/doc/go1.25) (`WaitGroup.Go`, `synctest.Test`), [1.26](https://go.dev/doc/go1.26) (`errors.AsType`, `go fix` modernizers), [1.27](https://go.dev/doc/go1.27) (`httptest.NewTestServer`)
- [`net/http` `ServeMux`](https://pkg.go.dev/net/http#ServeMux), [`Server` timeouts and `Shutdown`](https://pkg.go.dev/net/http#Server) (`ErrServerClosed` returns immediately; the program waits for `Shutdown`), [`Client.Timeout`](https://pkg.go.dev/net/http#Client) (zero means none; clients are reused)
- [`os/signal.NotifyContext`](https://pkg.go.dev/os/signal#NotifyContext), [`os.Exit`](https://pkg.go.dev/os#Exit) (deferred functions do not run)
- [`context`](https://pkg.go.dev/context) (first parameter, not in a struct, `WithoutCancel`, `AfterFunc`) and [Code Review Comments: Contexts, Interfaces, Goroutine Lifetimes](https://go.dev/wiki/CodeReviewComments)
- [`errgroup`](https://pkg.go.dev/golang.org/x/sync/errgroup) (`WithContext`, `SetLimit` before `Go`), [`sync.WaitGroup.Go`](https://pkg.go.dev/sync#WaitGroup.Go) (`f` must not panic), [`close`](https://pkg.go.dev/builtin#close) (sender only)
- [Go 1.13 errors](https://go.dev/blog/go1.13-errors) (`%w` makes the cause part of your API), [`errors.AsType`](https://pkg.go.dev/errors#AsType)
- [`sync/atomic` types](https://pkg.go.dev/sync/atomic#Int64) and [`sync.Mutex`](https://pkg.go.dev/sync#Mutex) (no copy after first use), [race detector](https://go.dev/doc/articles/race_detector) (finds races only on executed paths)
- [`testing.T.Context`](https://pkg.go.dev/testing#T.Context), [`T.Setenv`](https://pkg.go.dev/testing#T.Setenv) (not in parallel tests), [`B.Loop`](https://pkg.go.dev/testing#B.Loop), [`testing/synctest`](https://pkg.go.dev/testing/synctest) and [Testing Time blog](https://go.dev/blog/testing-time) (stable in 1.25; network I/O is not durably blocking), [`httptest.NewTestServer`](https://pkg.go.dev/net/http/httptest#NewTestServer)
- [`os.Root`](https://pkg.go.dev/os#Root)
- [When to use generics](https://go.dev/blog/when-generics), [module layout](https://go.dev/doc/modules/layout), [Go toolchains](https://go.dev/doc/toolchain) (`go` line is the minimum; omitted `toolchain` line is implied), `go help get` (`-tool`), `go help fix`

Left out because unverified or owned elsewhere: `go vet` in CI (golangci-lint's default `govet` already runs it), `govulncheck` (`security`), and mutex field placement conventions.
